#  Rev-Enue

A React single‑page app that improves the car‑buying experience by asking users a short series of questions, then recommending vehicles that best match their needs. 
The app filters a local JSON dataset and presents paginated, card‑style results.

## Features:

* Question Wizard: Progressive, friendly flow that captures preferences (budget, size, fuel type, transmission, MPG range, etc.).

* Smart Filtering: Deterministic filters applied to a local dataset (/public/carDatabase.json).

* Results UI: Paginated car cards with key specs and quick actions.

## Tech Stack

* React (Vite) + JavaScript
* Python
